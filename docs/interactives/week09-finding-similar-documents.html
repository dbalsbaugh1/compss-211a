Finding similar documents

Week 9 · Document similarity 5–10 minutes Eight made-up comments

This page runs the Lab 9 workflow on eight short campus comments. Turn each comment into a TF-IDF row, score every pair with cosine similarity, find the comments closest to one anchor, and read the shared terms behind each score. Sorting the comments into groups with KMeans is an optional last step. The numbers come from scikit-learn with the settings shown in the code.

1·One row per document

TfidfVectorizer turns each comment into a row of numbers, one number per term. That row is the document vector. Click a comment to see the terms in its row that are not zero. Stopwords such as the and too are removed, so they have no column. 

    vectorizer = TfidfVectorizer(stop_words="english")
tfidf_matrix = vectorizer.fit_transform(comments)
tfidf_matrix.shape   # (8, 43): 8 comments, 43 terms

    2·Score every pair with cosine similarity

    cosine_similarity(tfidf_matrix) returns an 8 × 8 table. Row i holds the scores between document i and every document. A score of 0 means the two documents share no terms. TF-IDF weights are never negative, so scores stay between 0 and 1. Click a cell to see which shared terms make up its score.

    Click a cell to compare two documents.
    similarity = cosine_similarity(tfidf_matrix)
similarity.shape   # (8, 8)

    3·Find and read the nearest documents

    Pick an anchor. The page sorts its row of scores from high to low, skips the anchor itself, and keeps the next three. Click a neighbor to read both comments and the terms they share. Each shared term adds the product of its two weights, and the products add up to the score.

      KMeans puts each document into one of n_clusters groups so that documents in a group have similar rows. random_state=211 fixes the starting point, so you get the same groups every time. That makes the result repeatable. It does not make the groups correct. The group numbers are labels, not rankings. Each group shows the four terms with the highest average weight.
